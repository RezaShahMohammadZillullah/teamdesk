TeamDesk Privacy Policy

Publisher: Vartex Engineering · Effective Date: 2026-11-19

Vartex Engineering ("we", "our", or "us") provides TeamDesk (https://teamdesk.vartexengg.com) as a remote desktop support and screen-sharing application. This Privacy Policy explains what information is processed when you use TeamDesk and how your privacy is protected.

1. Explicit User Consent & Transparency

  • TeamDesk never performs hidden or silent background screen capture or remote input control.
  • Screen sharing and mouse/keyboard control only start after the host user explicitly approves the session and keeps the active session indicator visible on screen.
  • The host user can terminate any active remote session or exit the local desktop helper at any time with one click (End Session or Exit).

2. Information Processed During Use

  • Session & Routing Identifiers: Temporary Peer IDs and Workspace names are used solely to establish peer-to-peer or relayed connections between authorized participants.
  • Real-Time Media & Input Streams: Screen video, optional audio, pointer annotations, and approved mouse/keyboard control events are transmitted over encrypted HTTPS/WSS/WebRTC channels strictly between connected peers during an active session.
  • Shared Files & Chat: Files or text messages explicitly sent by users during a session are delivered directly to the session participant.

3. Data Retention & Third-Party Sharing

We do not sell, rent, or trade user data, and we do not use screen streams or input events for advertising or profiling. Live screen video and remote mouse/keyboard events are ephemeral and are not permanently recorded or stored on our servers unless a user explicitly chooses local recording on their own device.

4. Security

All signaling and media transport uses modern encryption (TLS/HTTPS, WSS, and DTLS-SRTP for WebRTC). Local desktop control commands are restricted to authenticated, user-approved sessions matching the active Peer ID.

5. User Control & Contact

You may stop using TeamDesk, clear browser storage, or uninstall the Windows application at any time. If you have questions about this Privacy Policy or wish to request deletion of any workspace metadata, please contact us at: zillullahreza@gmail.com.
